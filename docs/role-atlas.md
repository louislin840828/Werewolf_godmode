# 0.47 角色圖鑑

## Review 與範圍

Chrome 真實點擊原「隱藏」按鈕後仍是遊玩畫面，global hidden 為 false。inline onclick 的 hidden 名稱與 HTMLElement.hidden 衝突；直接在全域設定 hidden 後才出現遮罩，證明呈現分支有寫但按鈕未接通。先前僅看程式碼宣稱已實作並不完整。

使用者確認改為全角色圖鑑：24 位角色名稱／縮圖集卡冊，點卡展開完整大圖、名稱與大致技能。不加本板／全部篩選，不呈現任何玩家身分、技能草稿或本局資源。

## 實作

src/role-atlas.view.js 提供靜態 ROLE_ATLAS、冊頁／詳情與返回操作，只使用呈現暫存，不操作 engine。右上角命名 openRoleAtlas() 取代原 inline 隱藏入口。沿用 host drawer 焦點陷阱、Escape、墨色主題和肖像快取，冊頁 3 欄、小於 371px 為 2 欄；大圖 contain 不裁切。返回保留捲動位置及原卡片焦點，關閉返回右上角入口。

技能是概覽，並非新的規則來源。白痴分板差異、狼王／白狼王、血月封印、隔夜繼承與技能生效時機沿用 docs/boards.md。舊隱藏分支保留供相容，已不再有右上角入口。

## 檢查

Node v24.22.0 全套 25 支，新增 role-atlas-check：角色／圖片清單一致、冊頁 24 張、合法詳情／返回、不改 state／選取、不顯示玩家資訊、重要家規文案。角色邊界與 build 檢查。

真實 Chrome：實際點擊右上角圖鑑與黑市商人卡片，顯示大圖／技能，快照 state 不變；返回還原 scrollTop=400、焦點回卡片，Escape 關閉後焦點回入口。320×700、390×844、430×932、844×390 冊頁 24 張、可內部捲動、無整頁橫向溢出。390×844 截圖確認墨色冊頁與大圖 contain。

未驗證：iPhone／Android 實機、所有角色詳細視覺／讀屏、低網路載入效能。無遠端推送或部署。
