## 本機安全套用

將下載的 `moonlit-visual-0.45.0.patch` 放在專案資料夾外，再於專案根目錄執行：

```sh
git status --short
git rev-parse HEAD
```

第一行必須沒有輸出，第二行必須等於上述完整基準。若有未提交修改，先自己保存到獨立 commit；若 GitHub/main 已前進，應重新比對，請 Agent 協助整合。不要強制套用或覆蓋現有工作。

```sh
git switch -c visual/graphic-novel-review
git apply --check /實際路徑/moonlit-visual-0.45.0.patch
git apply /實際路徑/moonlit-visual-0.45.0.patch
npm test
npm run dev
```

`--check` 失敗即停止；不要加 `--reject`、強行忽略空白或自行刪檔繞過衝突。
開啟 localhost 與同 Wi-Fi 手機驗收。通過後自行 `git add`、`git commit`，再選擇推分支開 PR 或本機合併 main。原 main 未被這些套用命令修改。
