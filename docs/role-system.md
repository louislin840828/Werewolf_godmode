# 角色狀態系統 v1

七個固定板子共用 RoleSystem 狀態規格。既有板子的原始欄位保留為寫入來源，
透過規則轉接層計算共用狀態，避免同一個資源存在兩份可獨立修改的資料。

## 共用狀態

| 類別 | 欄位 | 定義 |
| --- | --- | --- |
| 認牌 | registered | 未認牌不推定為好人或平民 |
| 身分 | originalRole / currentRole | 盜賊選牌改目前角色；機械狼學習不改本體 |
| 陣營 | originalAlignment / alignment | 勝利陣營可改，具體角色保留 |
| 屠邊 | edge | wolf / god / villager / other / unknown；第三方仍依本體計入 |
| 生命 | alive / life / death | alive、delayedDeath、dead；死因保留多個因素與夜/日時間 |
| 權限 | canSpeak / canVote / canAct | 分別計算，含退水輪次、白痴發言、恐懼與封印 |
| 技能 | skills | 技能、剩餘次數、生效夜、限制來源、上次目標 |
| 待處理 | pendingAbilities | 出局後仍待處理的槍或白狼帶人 |
| 效果 | effects | 來源、目標、起訖時間、防禦範圍 |
| 關係 | relationships | 情侶、兄弟、攝夢連結 |
| 進程 | progression / learned | 狼弟覺醒階段、機械學習內容 |
| 資訊 | inspectionRole / knowledge | 當下查驗回報與當時已確認告知的資訊 |

## 共用判定

傷害結算保留多個因素。中毒、殉情、連續攝夢、攝夢牽連、自爆均禁止死亡開槍；
夢魘恐懼限制當夜槍，不能延伸成翌日放逐禁槍。白狼王帶人是不同能力，
其自爆帶人資格不能套用一般槍的自爆禁槍條件。

戀人只有一位遭直接致命傷時，另一位為殉情者。兩位同夜各有直接致命傷時，
兩位皆保留直接死因與殉情因素，死亡批次順序不得改變開槍權。

只有血月白天自爆封印下一夜。最後黑夜仍保留正常好人技能、解藥及守護。
先完成同批有效死亡與自動牽連並判勝；未分勝負才處理待發動技能。
夜間屠邊優先於同批清狼，第三方按勝利陣營判斷。詳見 [勝負與預測](victory-and-forecast.md)。

## 時間與事件

事件帶有 id、round、phase、step、type。包含認牌、角色改變、資源/關係變化、
階段切換、死亡因素及已告知資訊。最近 2048 筆結構事件保留在存檔；完整中文
時間線及已確認資訊另行保留。這不是將遊戲完全改為事件回放架構。

暫時效果在夜間結算期間有效，保留到必要的夜槍牽連處理結束；下一夜不沿用。
學習主動技能次夜生效，獵槍當夜生效；狼刀繼承使用死亡時間判定隔夜資格。

## 存檔與撤回

存檔 key 沿用既有版本；roleSystem.schemaVersion = 1。舊存檔增補共用 metadata，
保留角色、藥水、草稿、警長階段、關係及歷史。舊版沒有記錄的資訊不可憑空補造；
可識別的死因由既有時間線轉換，無法辨識者標示為舊存檔未知。

撤回快照記錄事件游標，不重複複製整份事件與資訊紀錄。撤回或重新認牌時，
依游標還原紀錄，並一起恢復角色、關係、資源、死亡與待處理能力。

## 介面與規則的隔離

GameEngine.read / role / roles / events 回傳不可直接修改的副本。
GameEngine.register / choose / advance / settle 等操作由控制層提交並驗證。
畫面、CSS、村莊繪圖與原生手冊均獨立於規則檔案；架構檢查禁止畫面存取 live s
或直接執行底層死亡、勝負與階段結算。既有七板仍使用個別流程 adapter，
尚未加入自訂人數、任意角色組合或尚未定義的跨板技能衝突。
