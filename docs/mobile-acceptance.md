# 手機封閉測試驗收

以下項目目前是**待執行清單**，不是已通過的測試報告。
至少使用一台 iPhone Safari 與一台 Android Chrome；記錄裝置、系統、瀏覽器版本。
以固定測試網址、一般瀏覽模式、單一分頁操作，避免把換來源誤認為存檔失效。

## 0.44.1 遊玩流程擴充（部分 Chrome 驗證，實機待驗收）

Chrome 390×844 已查看警長退水、黎明雙結果、遊玩角色介紹及白天投票；不是 iPhone／Android 實測。新增待驗收：上警／PK／退水恢復、黎明槍與警徽、結束與隱藏畫面、盜賊備選／選牌、必勝提示／略過、跨階段城市不回到舊 painter、第二夜回合提示、320／430px 與橫向。罕見元件的 computed-style fixture 只證明 CSS 接入，不代表其對局驗收完成。

## 圖像小說第一階段（原始待驗收清單）

詳見 [visual-design.md](visual-design.md)。測試 320×740、390×844、430×932 及 844×390；本次無瀏覽器控制能力，沒有截圖或實測通過紀錄。

- 夜間狼刀選取為金、4 狼對一目標各自有線；毒線也為金，多目標不漏線。
- 座位仍固定 10／12 席，不因死亡移位；命運標記整顆可點，文字不擋點擊。
- 白天城市亮但面板墨色，短討論內容填滿；投票者／對象／已記錄／棄票／修改為中立灰藍，與陣營無關。
- 長角色名、長暱稱、48px 多目標摘要、確認前後按鈕位置、安全區及橫向無整頁破版。
- 查驗揭示／返回、出局文字／虛線、槍／警徽／撕毀、取消、撤回及第二局圖片快取正常。
- reduce-motion 不阻擋操作；城市安靜、技能線不持續流動。其他頁面目前不屬新視覺驗收範圍。

## 介面與恢復

- 首次進首頁：目前板子圖先出現；左右切換正常，往下滑不誤觸橫移；點卡再確認。
- 確認板子：角色準備進度含平民；失敗後可重試；準備中關閉詳情不應誤開局。
- 首夜不預先知道角色；逐位認牌可選取取消、清空、撤回重認，已確認技能也跟著恢復。
- 角色第一次出場：操作區與彈窗無長時間空白、無低解析圖；查驗結果不溢出。
- 環繞 12 席可點，選中／行動者與技能連線可辨；多對一／一對多呈現多線。
- 角色詳情、紀錄、管理、角色圖鑑、返回與關閉正常；不被安全區／底部遮擋。
- 玩家暱稱、筆記輸入時軟鍵盤不蓋住操作；關閉鍵盤後高度恢復；長文字不擠出版面。
- 棄票、改票、退水、第二輪投票權、雙爆中斷／恢復與無警徽流程正常。
- 天亮同時公布所有死訊，無逐個提示死因；出局技能及警徽按序處理。
- 已確認操作後重整，應回到已保存進度；未確認認牌選取、未送出筆記、timer 可重設。
- 手機鎖定後返回、切換 App 再返回，確認進度及可操作性；不要把 timer 當成持久化時鐘。
- 管理入口可看到專案版本；文字紀錄匯出可在手機正常操作。

## 0.41.0 投票統整視窗（待實機驗收）

- 警長投票結束：黎明畫面中央顯示「警長結果」（當選／唯一候選人／警徽流失與原因）及票數／棄票數；長名單不溢出。
- 放逐投票結束：若有獵人槍或白狼帶人，先能點選場上座位、完成待處理技能與警徽，不讓結果卡遮住目標；隨後白天裁決畫面才顯示「放逐結果」與本次所有出局者、總人數及死因。平票無放逐仍顯示無人放逐；入夜後不再重現。
- 殉情自動出局要列入同一批；攝夢人白天出局不牽連夢遊者，夜間夢境牽連仍屬黎明死訊。
- 平票進入 PK：第二輪投票層與警長 PK 發言保留第一輪票數提示；第二輪結算後更新為最終結果。
- 結果視窗與夜死名單同時出現時依序排列；撤回可復原；跨夜後不重現舊結果。

## 0.40.2 語意過渡（待實機驗收）

- 開局與對局開關管理抽屜有一致進出節奏；板子詳情開關正常，原生 dialog 焦點／遮罩無殘留。
- 玩家／紀錄／管理切頁籤只換內容，不重播抽屜容器；名冊進詳情／返回有成對輕微方向感。
- 返回名冊恢復原捲動與玩家入口焦點，關閉抽屜返回原入口；介紹內 Tab 不跑出彈窗。
- 查驗揭示／返回不重播口令、不收起同回合資訊；選號碼／技能／投票不重播回合。
- 日夜背景與面板同步過渡；公布死訊只更新座位與結果，不交疊整個環境。
- 快速開關／換回合只保留最新畫面；圖鑑開關不改對局；靜態場景保留導覽回饋但停止持續動態，reduced-motion 不平滑捲動。

## 0.40.1 互動修正（待實機驗收）

- 黑市商人先選號碼再選技能、先選技能再選號碼都正常；更換技能不必重點號碼，更換號碼保留技能。
- 交易摘要同時顯示號碼／技能；只選一項時提示缺少的項目，今晚不交易可取消本回合選取。
- 投票記錄數票（含棄票）後重整，回執顯示已恢復票數，仍可改票、續投及正常結算。
- 管理入口按開新局後取消，抽屜與對局保持；確認後才返回選板畫面。
- 出局開槍並列開槍／放棄；切模式不立即結算，主按鈕文字符合模式，點目標恢復開槍，撤回可復原待處理槍。

## 0.40 混合轉場

- 同回合選座位、換技能、記錄下一票，不重播口令與查驗結果動畫；村莊微動態不中斷。
- 回合標題／口令短淡入，日夜村莊與操作面板共同過渡；不延後結算、存檔或必要操作。
- 快速連續換回合、撤回、開關彈窗／抽屜，無殘留遮罩、重複技能送出或焦點困住。
- 同回合展開資訊、捲動、筆記輸入保持；換回合展開選项重設，主操作可見。
- 天亮公布死訊時，手機場景保留最低高度；多名死者可完整閱讀。
- 圖鑑返回還原冊頁捲動與焦點；關閉回入口，不改技能選取。0.48 已移除舊隱藏模式。
- 靜態場景停止環境與持續裝飾動態但保留導覽回饋；系統減少動態效果無 JS 轉場；切換系統設定後下一次操作符合設定。
- 慢網路圖片由剪影淡入；同頁第二局正常，成功圖片不重複解碼。
