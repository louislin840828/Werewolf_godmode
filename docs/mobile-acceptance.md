# 手機封閉測試驗收

以下項目目前是**待執行清單**，不是已通過的測試報告。
至少使用一台 iPhone Safari 與一台 Android Chrome；記錄裝置、系統、瀏覽器版本。
以固定測試網址、一般瀏覽模式、單一分頁操作，避免把換來源誤認為存檔失效。

## 當前追加驗收（0.49.3）

- 一般四板白天技能區直接可見狼人自爆卡，點後直接點合法座號，不要求輸入數字；選號與取消不造成死亡。狼兄／石像鬼不可选、機械狼依設定、已出局不可選，狼弟與普通狼／10 席狼王沿用原資格。
- 取消卡直接可達，取消不重播介紹；確認後出局、勝負／警徽續接與撤回保留，投票開始後卡片消失且過期確認不能繞過。
- Chrome 390×844 狼兄弟隔離 fixture 部分互動通過；其他板、320／430px、橫向與實機完整流程待驗收。

## 0.49.2 追加驗收

- 八板白天討論可自爆（依角色資格）；按開始放逐投票後，零票／一票／棄票／改票／PK 都不能自爆，玩家存活、票單、階段、資源與撤回歷史不受拒絕操作影響。
- 警長發言／退水仍可投票前自爆；開始警長投票後，零票、一票、平票 PK 發言與第二輪關閉自爆。開啟自爆選擇後若進度改變，不得用舊確認視窗結束投票。

### 首輪首載速度（實機待測）

24 張正式角色 WebP 實際合計 **33,527,942 bytes（33.53 MB／31.97 MiB）**；這是素材總量，不代表首次進頁必定全部下載。用固定 HTTPS 網址，記錄 iPhone Safari／Android Chrome、裝置／瀏覽器版本、Wi-Fi／行動網路與冷／暖快取條件。

- 首次開啟：量測導覽到首頁可操作、板子圖可見；記錄實際下載量／請求數，不把剪影出現視為原圖完成。
- 切板與打開詳情：量測原圖出現及確認可按時間；確認沒有等待無關 24 張圖才可操作。
- 開局及每個角色首次出場：量測準備等待、進入按鈕可按與原圖解碼完成；慢網路／失敗仍能繼續。
- 同頁第二局、同板／換板：確認成功快取重用，沒有主動清快取重載。保持正式素材品質，先量測再決定載入优化。
- 清圖片快取的測試不得誤清對局 localStorage；不可為量測刪掉使用者進行中的局。

### 首輪進度恢復（實機待測）

固定網址、同一一般瀏覽器、單一分頁，用專用測試局：

- 認牌確認、技能確認、部分投票（含棄票）、投票結算後各重整，核對角色／資源／目標／票單／日夜階段及投票鎖。
- 重整後撤回開始投票、技能確認、死亡與警徽，核對票單、資源、關係、待處理技能與結果一起復原；再重做／重整確認一致。
- 未確認認牌座位、計時器／彈窗等 UI 暫存與已保存對局分開回報。
- 文字復盤匯出**不可還原對局**；不以匯出文字當成完整備份或恢復驗證。完整存檔匯出／匯入仍暫不開發。

## 圖像小說第一階段（原始待驗收清單）

詳見 [visual-design.md](visual-design.md)。測試 320×740、390×844、430×932 及 844×390；此原始清單產生時無瀏覽器控制能力；後續部分 Chrome 結果見各版本紀錄，實機項目仍待執行。

- 夜間狼刀選取為金、4 狼對一目標各自有線；毒線也為金，多目標不漏線。
- 座位仍固定 10／12 席，不因死亡移位；命運標記整顆可點，文字不擋點擊。
- 白天城市亮但面板墨色，短討論內容填滿；投票者／對象／已記錄／棄票／修改為中立灰藍，與陣營無關。
- 長角色名、長暱稱、48px 多目標摘要、確認前後按鈕位置、安全區及橫向無整頁破版。
- 查驗揭示／返回、出局文字／虛線、槍／警徽／撕毀、取消、撤回及第二局圖片快取正常。
- reduce-motion 不阻擋操作；城市安靜、技能線不持續流動。其他頁面自 0.46 已納入一致性驗收。

## 介面與恢復

- 首次進首頁：目前板子圖先出現；左右切換正常，往下滑不誤觸橫移；點卡再確認。
- 確認板子：角色準備進度含平民；失敗後可重試；準備中關閉詳情不應誤開局。
- 首夜不預先知道角色；逐位認牌可選取取消、清空、撤回重認，已確認技能也跟著恢復。
- 角色第一次出場：操作區與彈窗無長時間空白、無低解析圖；查驗結果不溢出。
- 環繞 12 席可點，選中／行動者與技能連線可辨；多對一／一對多呈現多線。
- 角色詳情、紀錄、管理、角色圖鑑、返回與關閉正常；不被安全區／底部遮擋。
- 玩家暱稱、筆記輸入時軟鍵盤不蓋住操作；關閉鍵盤後高度恢復；長文字不擠出版面。
- 棄票、改票、退水、第二輪投票權、雙爆中斷／恢復與無警徽流程正常。
- 天亮同時公布所有死訊，無逐個提示死因；出局技能及警徽按序處理。
- 已確認操作後重整，應回到已保存進度；未確認認牌選取、未送出筆記、timer 可重設。
- 手機鎖定後返回、切換 App 再返回，確認進度及可操作性；不要把 timer 當成持久化時鐘。
- 管理入口可看到專案版本；文字紀錄匯出可在手機正常操作。
