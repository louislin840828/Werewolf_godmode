# 月夜議會｜圖像小說視覺契約

## 產品與第一階段

實體狼人殺真人上帝的手機輔助器。上帝從全知視角看共享中古城市，掌握主持節奏及最終決定；操作要能快速理解並迅速回到現場。
世界是和平城市被極光籠罩：狼的野性偏緋紅、神職與上帝力量偏金、平民保留日常。不把角色肖像拼成城市背景。

0.44.1 依使用者確認將新版風格延伸至完整遊玩流程：夜間行動／認牌／特殊選牌、警長上警／發言／退水／PK／投票、黎明、白天討論／投票、出局技能／警徽、結束及遊玩中的角色介紹與隱藏身分。角色美術原圖不改；選板、玩家名冊／詳情、紀錄與管理抽屜不在本輪範圍。
參考使用者提供的直向構圖：城市、環繞數字、墨色操作媒介；不將該整頁 JPG 當成背景、不複製其密集金色框與強光。

## 技術與可替換素材

- `src/graphic-play.css`：最後載入的限定 `.graphic-play` token／元件，不改全域 :root，避免改到未核准的頁面。
- `src/game.js`：只加入呈現範圍、互動色彩語意及命運標記 class。保留原 data-seat、座位順序、命名操作、選取／确认流程與圖片快取。
- `src/city-render.js`：純 Canvas 2D 城市繪圖，無玩家／角色／技能資料；決定性筆觸避免每次重畫跳動。可在 drawGraphicCity 接點替換為正式城市素材。
- `src/village-render.js`：第一階段轉接城市 painter，保留 resize、Canvas 重用與日夜過渡。其他階段目前仍沿用既有場景。
- 角色 WebP 與 ROLE_ART 映射、portrait()／解碼準備／剪影備援保持不變。不降低品質、不重新生成。
- 不改規則、controller、角色模型、勝負預測、localStorage key／schema；夜間一瓶藥、死亡槍、10 人變體、首夜認牌均按現行契約。

## 元件與狀態

### 命運標記

固定環繞座號、角色名輔助、整顆 button 點選。保留 10／12 席位置計算及 data-seat keyed 節點，出局不移位。
- 一般：淡石色墨線、深墨底、大座號。
- 行動者：虛線輪廓＋既有「行動／投票」文字。
- 已選：金色（技能）或灰藍（票）輪廓＋✓，不改位置或尺寸。
- 出局：灰色虛線＋「已出局」，不得只靠降低透明度。
- 不合法目標：降低強度，但保持座號可辨；正式合法性仍由 controller 驗證。
- 警徽沿用 ♛；投票數沿用文字徽記。

### 操作媒介

墨色底、不規則角與極少表面筆線；沒有金屬框與滿版 glow。一般卡片安靜，只有當前技能／選取有金線。on 狀態附 aria-pressed；已選目標／已記錄資訊有文字／勾號。保留所有取消、改選、棄票、槍、警徽、撤回入口。

主確認用力量色，投票確認用中立色，disabled 使用獨立墨灰底且保留文字。選取不立即提交致死／切夜／技能消耗。
摘要沿用固定 48px 列；多目標可在列內橫向閱讀，不擠動確認按鈕、不使整頁橫向溢出。長操作文字可換行。

### 城市與連線

城市是靜態／安靜的共用背景，不與玩家生命連動建築，不綁住所。乾筆／墨線以確定性幾何實作，不做擬真 3D。低對比場景覆蓋，避免搶座號與技能線。
線仍由正式 actorIds／actions／draftValue 產生；不只畫第一個來源或目標。金色虛線不持續流動，日夜構圖一致。

### 動態與快取

既有局部狀態／日夜淡入淡出保留，不等待動畫提交操作；新城市無持續 Canvas 動畫。reduced-motion 與靜態設定有效。保留 portraitPreload／portraitNodes／preparedPortraits，不連開第二局重新清空。

## 第一階段驗收

自動驗證是 Node／VM、CSS 範圍與 Canvas 呼叫，不是瀏覽器實測。
必須補真實瀏覽器 320×740、390×844、430×932、844×390（橫向），至少：
- 狼刀改選／取消／確認；長角色名與暱稱；多來源與多目標線。
- 查驗揭示／返回；死亡標記；槍及警徽移交／撕毀／取消。
- 白天短內容填满；投票者／對象／記錄、棄票、修改、PK。
- 10／12 席不重排與完整命中區；長文字、安全區、無全頁橫向溢出。
- 48px 摘要選取前後確認位置不變；縮短視窗／軟鍵盤。
- 撤回與連開第二局圖片重用；reduce-motion／日夜不鎖操作。

0.44.0 當時未取得 control-browser 能力。0.44.1 已使用獨立 Chrome 測試 session 於 390×844 檢查投票、警長退水、黎明結果及角色介紹，並保存截圖；罕見選牌／預測／回合提示以獨立 DOM fixture 驗證 computed style（非完整對局）。新版標記是否啟用已納入 Canvas 重用簽章。320／430px、橫向、實機 Safari／Android、效能及全部特殊對局仍保持未驗證。
