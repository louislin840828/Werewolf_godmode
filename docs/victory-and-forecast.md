# 勝負結算與綁票預測（0.30.1-beta.1）

2026-10-15 同好會確認家規。此文件取代舊版「待處理槍先於勝負」的規則。

## 實際判勝

1. 先算有效防禦，再處理同批有效死亡與自動牽連。夜間的刀、毒、連續攝夢、
   攝夢牽連及殉情全部同批；不可因座號迭代順序提前判勝。
2. 若仍存活者全屬人狼戀第三方，第三方屠城獲勝。
3. 夜間批次達成屠神／屠民，且此批次開始時有原狼人陣營成員，原狼人陣營優先勝利。
   即使該批次也殺死最後一狼，仍為狼人勝。傷害不必來自狼刀。
4. 未符合以上夜間優先條件，所有狼牌出局則好人勝；仍有原狼人陣營存活且屠邊，狼人勝。
5. 未分勝負才處理槍／帶人；每次技能及自動牽連完成後，再判勝。
   已分勝負時清除待發動技能、警徽交接與入夜排程。
6. 白天最後一狼出局即好人勝，白狼王不再帶人。血月作為最後一狼被放逐仍保持
   暫時存活，照原規則進最後黑夜；只有血月白天自爆封印好人技能。
7. 第三方的實體角色仍計入神／民／狼邊，但人狼戀的狼不能分享原狼人勝利。
   人狼戀自己把最後一狼弄死、未達第三方屠城時，依好人清狼條件判好人勝。

`s.victoryContext` 只記錄本次結算的日夜性質與原狼人陣營是否參與。
第一個死亡前擷取，牽連沿用；`checkWin()` 在完整批次後消耗它。
判勝結果持續保存在 `s.winner`，撤回同時恢復整批狀態。

## 綁票預測

入口 `GameEngine.forecast()`。同一局面快取結果，輸入改變後重新計算。

- 白天公布死訊並處理完既有技能／警徽後，最多推算當日投票到下一夜結算。
- 放逐已完成時，只推算下一夜。
- 枚舉狼隊一致投票的合法策略，以及對方所有投票（含棄票、分票）。
  警徽 1.5 票；第一輪平票進 PK，PK 候選人不投票；第二輪平票無放逐。
- 白天包含騎士決鬥與死亡技能／警徽交接反制。
- 夜間先固定狼方行動，再檢查好人全部合法技能選擇；不讓狼根據尚未公開的守護
  選擇更改刀口。只要可能猜中守護而續命，即不提示必勝。
- 夜間合法目標／可用能力來自既有 `roleNightModel()`；資源提交及結算直接使用
  `nextNight()`、`settle()`、`kill()`、`checkWin()` 等正式流程。
- 白天尚未確認狼刀時，不能利用上帝看得到的隱藏身分，挑出唯一平民當成狼方必然會選中的目標；本版不建模狼人私下辨認身分的宣稱策略，故要求可成立的盲選目標策略，不然不提示。夜間狼刀目標確認後，則固定該刀口，推算本夜剩餘行動與完整死亡批次；有效防禦及自動牽連先結算，按正式夜間屠邊優先規則判勝，若勝負未定才檢查出局技能。提示可在夜間出現，上帝仍須明確按「宣告狼人勝利」，不會自動跳過剩餘夜間口令。
- 查驗等不影響本次勝負的夜間資訊行動合併等價分支；不能因此跨越資訊限制。
- 不假設狼方故意破壞勝局；搜尋一種能抵抗所有反制的策略即可。
- 推算只在同步隔離副本內執行，`finally` 還原正式狀態／交易函式；不呼叫存檔或呈現。
- `proven` 才顯示提示；`unproven`／`unknown` 都繼續遊戲，絕不視為好人獲勝。
- 上帝可略過提示，保留正常流程；同一局面略過狀態保存，仍可展開查看並宣告。
  宣告前重新取得目前局面結果，寫入紀錄與結構事件；可撤回。

## 主持人提示文字（0.30.5）

提示標題為「主持人專用 · 狼方有必勝策略」，依序說明推算範圍、策略摘要、
已考慮的阻止方式與結論。投票已結束時只描述下一夜，不假設必定有人被放逐。
投票前顯示警徽／1.5 票與首輪狼隊投票摘要；投票後顯示已記錄的狼方夜間行動摘要。
摘要不是完整操作步驟，也不代表狼方隨意操作都會贏；最遲獲勝期限包含下一夜結算。
文字不假裝提供逐分支證明或具體屠邊原因。提示只供主持人參考，不向玩家透露，
可提前宣告或繼續正常流程，不自動結束對局。此次只改文字，不改推算與勝負規則。

## 本版保守範圍

本版是有上限的證明搜尋，不宣稱能找到所有綁票局。

- 六名以內存活的殘局；最多 10,000 個搜尋節點／180 ms，超限回傳 unknown。
- 人狼戀第三方，以及獨立狼與小狼同時存活、未互認的局面，回傳 unknown。
  不會擅自把三方或隱藏隊友當成同一個可協作陣營。
- 不搜尋主動自爆搶先結束白天、分票狼策略或超過下一夜的多日策略。
  因此有些實務必勝局可能不提示；上帝仍照原有操作主持。
- 尚未結算的記票／PK、正在選白天技能、待處理槍／警徽時，不插入提示。
  投票結束後即重新推算；紀錄中保留的票單、PK 名單及輪次不阻擋提示。
- 新增能力欄位必須先加入預測支援與反制測試；未知能力不跳過，直接停止證明。
- 以上是推算範圍限制，不影響七板的實際勝負結算。

## 手機驗收情境

可從正常對局逐步形成以下殘局，不需要匯入存檔。確認對局管理版號 0.30.1-beta.1。

| 情境 | 預期 |
| --- | --- |
| 夜刀最後一民，同夜毒死最後一普通狼 | 公布整批死訊後狼人勝，無槍／警徽操作 |
| 夜刀最後一神獵人，手上還有商人獵槍 | 狼人勝，不開槍 |
| 夜死最後一狼、獵人，但還有其他神與民 | 好人勝，不開槍 |
| 最後白狼王白天放逐 | 好人勝，不帶人 |
| 最後血月放逐 | 延後死亡、進最後黑夜，好人技能未封印 |
| 人狼戀＋丘比特清除最後外人 | 第三方勝 |
| 人狼戀最後狼被放逐、戀人殉情 | 好人勝 |
| 放逐後 2 普通狼＋預言家＋平民 | 出現綁票提示，附可成立刀口策略 |
| 投票後 2 狼＋2 神（無守護）＋1 民，狼刀尚未選定 | 不因上帝知道誰是唯一平民就出現必勝提示 |
| 同局入夜後已確認狼刀唯一平民，狼方無守護能力 | 可在本夜出現提示；即使其後女巫毒死狼人，仍按夜間屠邊優先判狼勝 |
| 已確認狼刀但好人仍有可能阻止屠邊的合法技能 | 不提示必勝；繼續完成正常夜間流程 |
| 同上但為白天投票前，好人帶警徽 | 重新推算；可出現必勝，並非一律排除 |
| 2 普通狼＋守衛＋平民，守衛兩人都可守 | 不提前提示必勝 |
| 同上，但平民為上一夜守護目標 | 可證明刀平民必勝 |
| 女巫剩解藥、可自救，2 狼＋女巫＋平民 | 有反制，不提前提示 |
| 女巫剩解藥、不可自救，同上 | 可證明刀女巫必勝 |
| 點略過，再正常投票／入夜 | 正常繼續；提示縮為可展開資訊 |
| 宣告後撤回 | 恢復原白天、角色與資源、撤銷勝利事件 |
